In order to be able to run the code in the exercises, you will need to install the following requirements

### 1. **Install Python**
   - Make sure you have Python installed (preferably 3.8+).
   - Check by running:  
     ```sh
     python --version
     ```

### 2. **Create a Virtual Environment**
   - Run:  
     ```sh
     python -m venv venv
     ```
   - This will create a `venv` directory.

### 3. **Activate the Virtual Environment**
   - **Windows (CMD or PowerShell)**:  
     ```sh
     venv\Scripts\activate
     ```
   - **Mac/Linux**:  
     ```sh
     source venv/bin/activate
     ```

### 4. **Install Dependencies**
   - Run:  
     ```sh
     pip install -r requirements.txt
     ```


### 5. **Verify Installation**
   - Run:  
     ```sh
     pip freeze
     ```
   - This should list your installed packages.
